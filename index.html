SKILL

  • HTML5/CSS3

    FLOCSSをベースとした破綻しにくいディレクトリ構成、およびBEMに準拠した命名規則を意識してコーディングしています。共通パーツ（Component）や固有パーツ（Project）を適切に切り分け、コードの再利用性を高める設計が可能です。

    スマホやタブレットなどの可変要素、中間サイズでは、デザインの比率を維持したレスポンシブ実装を心がけています。

    Sassのネスト（入れ子構造）を活用し、BEMの命名規則（Block__Element--Modifier）に準拠した、可読性が高く破綻しにくいコードを記述します。

  • JavaScript / jQuery

    jQueryを用いたWebサイトの動的ギミックの実装が可能です。Swiperを活用したカルーセルやアコーディオンをはじめ、ボタンクリックで画面中央に浮き出るモーダルダイアログ、背景を黒く透過させてスムーズに展開するハンバーガーメニューなどを実装できます。

    画面をスクロールして要素を通過したタイミングで、上からふわっと出現するフェードイン演出など、ユーザーの視線誘導を意識した心地よいアニメーションを実装できます。

    `addClass` や `toggleClass` を用い、FLOCSSの設計思想に基づいた状態クラス（`.is-open` や `.is-active` など）を動的に制御することで、HTMLの構造に依存しない、保守・管理のしやすい堅牢なコードを記述します。

  • WordPress

    既存のHTMLサイトからのオリジナルテーマ化、カスタム投稿・カスタムフィールドを用いた管理画面のカスタマイズ、各種プラグインの導入・設定が可能です。（実装実績はWORKSの「作品1」を参照）

  • Photoshop

    レイヤー構造を理解し、スライスツールやアセット書き出し機能を用いた画像抽出、デザイン通りの正確なテキスト情報・カラーの再現が可能です。

  • XD

    カンプからの正確な数値（Margin / Padding）の計測、文字情報の取得、各種画像形式でのパーツ書き出しがスムーズに行えます。

  • Figma

    通常モード（閲覧権限）のインスペクトパネルからフォント、カラー、ウェイトの情報を正確に読み取ることができます。

  • PerfectPixel

    Chrome拡張機能の「PerfectPixel」を使用し、デザインカンプを背景に重ね合わせて検証しています。パーツの配置ミスや数ピクセルのズレも見逃さず、カンプを極限まで再現したコーディングが可能です。

ABOUT
